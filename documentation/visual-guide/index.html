Vocabulary

Ten words that carry the design

Event
One observation with an identity, a source, an event time and a typed payload. Evidence, never an instruction.
Event time and watermark
Event time is when something happened. The watermark says how far time has progressed, so windows know when they can close.
Window and operator
A window selects readings (here: the last 5 minutes, sliding every 30 s). An operator turns them into a feature such as a mean or a slope.
Situation and version
The durable record of one condition of one thing. Each publication is a numbered version that never changes afterwards.
Trigger and scheduler
Declared rules that say when a version deserves reasoning. The scheduler can ignore, queue, replace or admit it.
Episode and fence
One bounded reasoning session over one immutable snapshot, with a deadline and a budget. The fence rejects output from a stale attempt.
Decision and Intent
The reasoner's typed answer, and the typed action it proposes. A proposal, not a permission.
Policy and approval
Rules re-checked against current state just before dispatch. Higher-risk intents wait for a signed human approval.
Command and idempotency key
The governed request that may be dispatched. A retry carries the same key, so a device that honours it recognises the repeat instead of acting twice.
Outcome and verification
What the device reported, and a separate state query of what the output is now. Only a matching observation verifies the effect. "Unknown" is a legal outcome.
What is proven

Be precise about what this run shows

  • Proven in the recorded run: events to Situation, scheduler, one episode, a typed decision, policy approval, one governed command (set_indicator, risk R1), device receipt and result, and a verified state check.
  • Not physical hardware: a simulator played the sensor bench and a device emulator answered commands behind the gateway socket. The 3D bench and gateway show the designed physical setup, labelled as emulated.
  • Designed, not part of this run: the fan path (select_thermal_mode, risk R2) with signed human approval. It is shown in the film and the 3D world and labelled as such.
  • Known blind spots recorded with the run:
  • current ledgers have no execution identifier; exported rows are a tenant snapshot
  • gateway transport and firmware provenance are external to Agentic Stream
  • independent physical feedback verifier and HIL evidence are not stored by this repository
  • process-local telemetry is diagnostic and is not part of the safety verdict
