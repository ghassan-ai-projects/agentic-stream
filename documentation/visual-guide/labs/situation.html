Lab 2 · Stream plane

A condition changes state, not its mind every second

A noisy sensor crosses a threshold again and again. A Situation should not flap with it. Compare a naive single threshold with a spec-style rule (separate enter and exit thresholds, plus a minimum duration), and see why every change becomes an immutable, numbered version.

Reading the picture

Two machines, one signal

One synthetic signal drives both state machines. The strips under the chart show each machine's state over time and count its flips. Each flip of the spec machine publishes a version into the stack.

Key idea

Hysteresis and minimum duration

Enter above 30 °C, but only leave at or below 28 °C, and only believe a new state after it has held for a minimum duration. Small wobbles stop mattering.

Why it matters

Versions are facts, not drafts

A published version never changes. A correction publishes a new one, so you can always reconstruct what the system believed at the time, and every later step can point at exactly that version.

The signal is synthetic, for illustration. The 30 °C enter and 28 °C exit thresholds and the minimum duration default come from the experiment's bench spec (examples/real-world-sensor). Use the button to show the 22 versions of the recorded run instead.
