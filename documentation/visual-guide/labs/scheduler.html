Lab 3 · Cognition plane

Twenty-two versions, one episode

Reasoning is slow, costly and not repeatable, so a deterministic scheduler decides when it is worth starting. Replay the 22 real evaluations, then change the rules and the sensor's pace to see how the gate behaves.

Reading the picture

Evaluations, queue, episodes

The top row is every version with its score and outcome. The middle row is queued work with its not-before time. The bottom row is the episodes that actually started.

Key idea

Score, newness, then timing

A version must score above the threshold and be materially new. Queued work is delayed by a debounce, spaced by a cooldown, and replaced by newer work for the same trigger.

Why it matters

Rationed attention

Every outcome, ignored ones included, is a durable record with a reason. You can always answer the question "why did nothing happen?".

This is a simplified model of the scheduler. With the recorded settings it reproduces the recorded run: 22 evaluations, version 5 replaced by version 7, one episode about 21 s after the first admitted evaluation. The recorded run was fast-forwarded, so versions arrived a fraction of a second apart. For a live sensor, 30 s apart, the model predicts a second episode.
