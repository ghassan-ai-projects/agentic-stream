# Code of Conduct

We want Agentic Stream to be a constructive, technically rigorous project.
Participants must be respectful, assume good faith, and focus criticism on
ideas, evidence, and behavior rather than people.

Unacceptable behavior includes harassment, discrimination, threats, doxxing,
deliberate disruption, sharing private information without consent, and
retaliation against good-faith reports.

## Reporting

Report conduct concerns privately to the project maintainers through the
repository's [private reporting form](https://github.com/ghassan-ai-projects/agentic-stream/security/advisories/new)
until a dedicated conduct contact is published. Put `Code of Conduct` in the
report title so it can be routed appropriately. Do not include private
credentials or sensitive production data. Maintainers may remove, edit, or
reject participation that violates this code.

This code applies in project spaces and when someone is representing the
project publicly.
