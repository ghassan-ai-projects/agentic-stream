# Ubiquitous language

| Term | Meaning | Code name | Storage name |
| --- | --- | --- | --- |
| Runtime owner | The one process that holds the database lease and may write runtime state | `RuntimeOwner` | `runtime_owner` |
| Owner epoch | Opaque identity of one owner's tenure, generated by the runtime | `epoch` | `owner_epoch` |
| Lease | Time-bounded claim on ownership | `Lease` | `lease_until` |
| Epoch control | Drain or kill record for an epoch | `EpochControl` | `epoch_control` |
| Draining | New episodes refused; in-flight ones finish | `EpochDraining` | `state = 'draining'` |
| Killed | Terminal: decisions refused, in-flight episodes superseded | `EpochKilled` | `state = 'killed'` |
| Dispatch authorization | Read-only final readiness gate for one command | `NewDispatchAuthorization` | — |
| Cost ceiling | Aggregate spend limit for the global or a tenant scope | `CostCeilings` | `cost_limits.max_micro` |
| Kill switch | Rejects every new reservation in a scope | `KillSwitch` | `cost_limits.kill_switch` |
| Reservation | Cost held for an episode before admission | `Reserve` | `cost_reservations` (`reserved`) |
| Settlement | Actual cost recorded and the reservation released | `Settle` | `cost_reservations` (`settled`) |
| Cost ledger | The reservation/settlement operations on a transaction | `CostLedger` | — |

## Retired words

| Retired | Replacement | Why |
| --- | --- | --- |
| `costcontrol` (package) | `control` | One control plane |
| `Controller` | `CostLedger` | Names what it keeps, not a vague role |
| `SetLimit` / `Ceilings` / `ApplyCeilings` | `SetCostLimit` / `CostCeilings` / `ApplyCostCeilings` | Meaningful without a package prefix |
| `ErrReservationRejected` | `ErrCostReservationRejected` | Same |
